# Support

Trovul is maintained as a source-available project for people who use two PCs
on one desk. Community reports are the fastest way to improve device support and
real-world reliability.

## Where to ask

- Use [GitHub Issues](https://github.com/leoisrael/Trovul/issues) for a
  reproducible bug or a focused feature proposal.
- Use [SECURITY.md](SECURITY.md) for a suspected vulnerability; do not disclose
  security details in a public issue.

## A useful report includes

- Trovul version and Windows version;
- the two PCs' connection type: Ethernet, Wi-Fi, or mixed;
- output devices and any virtual audio software in use;
- exact steps, expected result, and actual result;
- sanitized logs or screenshots when relevant.

Please remove pairing tokens, file names, personal information, and anything
copied from your clipboard before sharing logs or screenshots.

Trovul does not promise individual support, compatibility with every device, or
a response-time SLA. Respectful, reproducible reports still make a real impact.
